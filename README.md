# **English**

## Introduction

Adds various catalyst types for Create's Encased Fan, expanding processing possibilities.

## Features

### Batch Withering
- **Catalyst**: Wither Rose
- **Configurable**:
  - Enable/Disable
  - Entity transformation list
  - Entity healing list and amount

### Batch Snow Flow
- **Catalyst**: Powder Snow
- **Configurable**:
  - Enable/Disable
  - Entity transformation list
  - Entity healing list and amount
- **Special Effect**:
  - Freezes entities in powder snow

### Batch Purifying
- **Catalyst**: Beacon
- **Configurable**:
  - Enable/Disable
  - Enable/Disable negative effect removal
  - Entity transformation list
  - Entity healing list and amount

### Batch Sculking
- **Catalyst**: Sculk Block
- **Configurable**:
  - Enable/Disable
  - Entity transformation list
  - Entity healing list and amount
- **Special Effect**:
  - Applies Darkness and Blindness to mobs

### Batch Resonance
- **Catalyst**: Amethyst Cluster
- **Configurable**:
  - Enable/Disable
  - Entity transformation list
  - Entity healing list and amount

### Batch Sand Blow
- **Catalyst**: Sand
- **Configurable**:
  - Enable/Disable
  - Entity transformation list
  - Entity healing list and amount

### Batch Breathed Wind
- **Catalyst**: Dragon Head
- **Configurable**:
  - Enable/Disable
  - Entity transformation list
  - Entity healing list and amount

### Batch Exploding
- **Catalyst**: Creeper Head
- **Configurable**:
  - Enable/Disable
  - Entity transformation list
  - Entity healing list and amount
- **Special Effect**:
  - Causes explosion on mobs


### Batch Honey Coating
- **Catalyst**: Honey Fluid
- **Configurable**:

  - Entity healing list and amount

### Batch Chocolate Coating

# **中文**

## 简介

为 Create 模组的鼓风机添加多种催化剂类型，扩展加工可能性。

## 功能特性

### 批量凋零 (Withering)
- **催化剂**：凋灵玫瑰
- **可配置**：
  - 是否启用
  - 实体转换列表
  - 实体治疗列表及治疗量

### 批量雪流 (Snow Flow)
- **催化剂**：雪块
- **可配置**：
  - 是否启用
  - 实体转换列表
  - 实体治疗列表及治疗量
- **特殊效果**：
  - 使实体进入细雪冻结状态

### 批量净化 (Purifying)
- **催化剂**：信标
- **可配置**：
  - 是否启用
  - 是否启用清除负面效果
  - 实体转换列表
  - 实体治疗列表及治疗量

### 批量幽匿 (Sculking)
- **催化剂**：幽匿块
- **可配置**：
  - 是否启用
  - 实体转换列表
  - 实体治疗列表及治疗量
- **特殊效果**：
  - 对生物施加黑暗和失明效果

### 批量共振 (Resonance)
- **催化剂**：紫水晶簇
- **可配置**：
  - 是否启用

### 批量扬砂 (Sand Blow)

### 批量爆炸 (Exploding)

- **可配置**：

  - 实体转换列表

### 批量裹蜜 (Honey Coating)
